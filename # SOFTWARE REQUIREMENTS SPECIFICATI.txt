**Smart Water Tank – Automatic Overflow Prevention System**

**Version:** 1.0

# 1. Introduction

## 1.1 Project Overview

Smart Water Tank একটি Automatic Water Level Control System। এই প্রজেক্টের মূল উদ্দেশ্য হলো পানির ট্যাংক উপচে পড়া (Water Overflow) প্রতিরোধ করা এবং পানির অপচয় কমানো।

সিস্টেমটি Ultrasonic Sensor ব্যবহার করে ট্যাংকের পানির উচ্চতা পরিমাপ করবে। Arduino সেই তথ্য বিশ্লেষণ করে পানির পরিমাণ নির্ধারণ করবে।

পানির পরিমাণ ৯০% হলে সিস্টেম স্বয়ংক্রিয়ভাবে পানির মোটর বন্ধ করবে। এরপর Manual Restart না করা পর্যন্ত মোটর বন্ধ থাকবে।

## 1.2 Problem Statement

সাধারণ পানির ট্যাংকে অনেক সময় ব্যবহারকারীকে নিজে থেকে পানির লেভেল পর্যবেক্ষণ করতে হয়।

এর ফলে:
- ট্যাংক উপচে পানি পড়ে।
- পানির অপচয় হয়।
- মোটর অপ্রয়োজনে চালু থাকে।
- বারবার ট্যাংকের পানির অবস্থা পরীক্ষা করতে হয়।

এই সমস্যাগুলো সমাধানের জন্য একটি Automatic Water Tank Controller তৈরি করা হবে।

## 1.3 Project Objectives

প্রজেক্টের প্রধান উদ্দেশ্য:

1. স্বয়ংক্রিয়ভাবে পানির লেভেল পরিমাপ করা।
2. পানির পরিমাণ Percentage হিসেবে নির্ণয় করা।
3. ট্যাংক ৯০% পূর্ণ হলে মোটর বন্ধ করা।
4. পানির Overflow প্রতিরোধ করা।
5. Manual Restart ব্যবস্থা রাখা।
6. কম খরচে ব্যবহারযোগ্য একটি Automation System তৈরি করা।
7. বাস্তব Hardware তৈরির আগে Proteus-এ Circuit Simulation করা।

# 3. Functional Requirements

সিস্টেমের Functional Requirements:

**FR-01: Water Level Measurement**  
Sensor ট্যাংকের পানির পৃষ্ঠ পর্যন্ত দূরত্ব পরিমাপ করবে।

**FR-02: Water Percentage Calculation**  
Arduino ট্যাংকের উচ্চতা ও পরিমাপ করা দূরত্ব ব্যবহার করে পানির Percentage নির্ণয় করবে।

Formula:

Water Level (%) = ((Tank Height - Measured Distance) / Tank Height) × 100

**FR-03: Automatic Motor OFF**  
পানির লেভেল ৯০% হলে মোটর বন্ধ হবে।

**FR-04: Motor Lock State**  
৯০% পূর্ণ হওয়ার পর পানির লেভেল কিছুটা কমলেও মোটর নিজে থেকে চালু হবে না।

**FR-05: Manual Restart**  
ব্যবহারকারী Manual Restart দিলে মোটর আবার চালু করার অনুমতি পাবে।

**FR-06: Serial Monitoring**  
Virtual Terminal-এর মাধ্যমে পানির দূরত্ব, Percentage ও Motor Status দেখা যাবে।

---

# 4. System Workflow

1. System Power ON হবে।
2. Ultrasonic Sensor পানির দূরত্ব পরিমাপ করবে।
3. Arduino Sensor Data গ্রহণ করবে।
4. Arduino Water Level Percentage হিসাব করবে।
5. পানির লেভেল ৯০% বা তার বেশি হলে Motor OFF হবে।
6. Motor OFF অবস্থায় Lock থাকবে।
7. Manual Restart দিলে পুনরায় Motor চালুর অনুমতি দেওয়া হবে।

# 5. Proteus Simulation Development

## Phase 1: Project Setup

1. Proteus 8 Professional ওপেন করতে হবে।
2. New Project তৈরি করতে হবে।
3. Project Name দিতে হবে: Smart_Water_Tank।
4. Schematic Capture নির্বাচন করতে হবে।
5. একটি নতুন Schematic Sheet তৈরি করতে হবে।

## Phase 2: Component Selection

Pick Devices (P) ব্যবহার করে প্রয়োজনীয় Component খুঁজতে হবে।

প্রথমে Arduino UNO R3, GUR03 Sensor, Relay এবং Virtual Terminal যোগ করতে হবে।

এরপর প্রয়োজন অনুযায়ী Transistor, Diode, Resistor, LED ও Push Button যোগ করতে হবে।

## Phase 3: Circuit Design

প্রতিটি Component-এর Pin Configuration যাচাই করে সঠিক Wiring করতে হবে।

প্রথমে Sensor ও Arduino Connection তৈরি করতে হবে।

তারপর Relay Driver Circuit, LED Indicator এবং Manual Restart Circuit যুক্ত করতে হবে।

## Phase 4: Arduino Programming

Arduino IDE ব্যবহার করে C/C++ ভাষায় Program লিখতে হবে।

Program-এর কাজ:
- Sensor Data Read করা।
- Water Level Calculate করা।
- ৯০% Threshold পরীক্ষা করা।
- Motor Control Logic পরিচালনা করা।
- Serial Output দেখানো।

## Phase 5: HEX File Integration

1. Arduino IDE-তে Code Compile করতে হবে।
2. Export Compiled Binary ব্যবহার করে HEX File তৈরি করতে হবে।
3. Proteus-এ Arduino-এর Properties খুলতে হবে।
4. Program File-এ HEX File নির্বাচন করতে হবে।
5. Clock Frequency 16 MHz রাখতে হবে।
6. Simulation চালু করতে হবে।

## Phase 6: Simulation Testing

বিভিন্ন Water Level পরিবর্তন করে System-এর আচরণ পরীক্ষা করতে হবে।

# 8. Safety Requirements

- 220V AC Motor সরাসরি Arduino বা Breadboard-এ সংযোগ করা যাবে না।
- Motor Switching-এর জন্য উপযুক্ত AC Contactor ব্যবহার করতে হবে।
- MCB, Overload Protection ও Earthing নিশ্চিত করতে হবে।
- Contactor-এর Rating Motor Nameplate অনুযায়ী নির্বাচন করতে হবে।
- বাস্তব Mains Wiring যোগ্য Electrician বা শিক্ষকের তত্ত্বাবধানে করতে হবে।
- Proteus-এ Motor-এর পরিবর্তে LED বা Virtual Load দিয়ে ON/OFF Logic পরীক্ষা করা হবে।
